# pr-assets

Screenshots referenced from pull request descriptions.

This branch exists only to host images. It is **not** part of the library:
it never merges into `main`, carries no Elixir code, and ships in no Hex
release. GitHub renders the PNGs in PR bodies via `raw.githubusercontent.com`
URLs pointing here.

Layout is one directory per PR:

```
pr-624-empty/
pr-625-hover-card/
pr-626-kbd-separator-collapsible/
```

Safe to delete once the PRs it serves are closed.
